## 0) الخلاصة التنفيذية (جملة واحدة)

Palmo يبني **عموداً فقرياً واحداً مستمراً**: مشهد 3D واحد (جوزة) يُثبَّت بالسكرول ويتحوّل تدريجياً (كاملة → تنفتح → تطير القطع → تتحول إلى علبة) بينما **النصوص والواجهات تُثبَّت حوله وتتبدّل في كل مشهد** — ثم يُكسر الإيقاع بقسم «ماركي/ران واي»، ثم فصول تحريرية، ثم منتجات، ثم **فوتر هو لعبة تفاعلية**.

**لأويق:** ننقل **المنهجية** (العمود الفقري التحويلي + التثبيت حول البطل + كسر الإيقاع + الفصول التحريرية) ونُكيّفها مع **الزجاجة 3D عبر الحضارات الأربع** — مع ضبط الشدّة لصالح الفخامة والانضباط (متطلب العميل: بسيط، أنيق، غير استعراضي).

## 1) كيف حللّته (المنهجية — قابلة للتكرار)

1. **التقاط حيّ:** متصفح Edge حقيقي عبر CDP (منفذ 9333) مع تعطيل إجبار `prefers-reduced-motion` ومحاكاة 1440×900.

## 2) التسلسل الكامل — مشهداً مشهداً (الدليل البصري)

### المشهد 0 — اللودر (`v2-00` قبلها، `loader-a/b`)
- **الشكل:** شاشة كاملة بنية داكنة، شعار نخلة ذهبي في المنتصف، عدّاد نسبة **«000%»** أسفل اليسار بخط ضخم.
- **التقنية:** `#loader` ثابت `z-999` مع **3 طبقات موجات** (`will-change-transform`) تتحرك بسرعات مختلفة (بارالاكس أثناء التحميل). العدّاد يتقدم 0→100%.
- **التوقيت:** اللودر ينتظر تحميل موديلات 3D (~5MB) ثم يختفي.
- **الدرس:** اللودر **ليس شاشة ملل** — هو تجربة بارالاكس مصغّرة تعدّ للعالم.

### المشهد 1 — الهيرو (`v2-00`)

- **التقنية:** الجوزة داخل `#coconut-canvas-pin` ثابت (`sticky`) — تبقى ثابتة بينما النص يمر. العنوان `invisible` ويُكشف عند الدخول (delay 0.25s). السهم `stagger: sequential`.
- **الدرس:** البطل 3D **ثابت بالنظرية** والنص يتحرك حوله — ليس مجرد صورة عائمة.

### المشهد 2 — الانفتاح (`v2-01`)

## 3) التشريح التقني (مؤكد بالكود)

### 3.1 البنية التحتية
| الطبقة | التقنية | الدليل |
|---|---|---|
| الإطار | **Next.js + Turbopack** (App Router) | `self.__next_f.push` + `turbopack-*.js` |
| الحركة | **GSAP + ScrollTrigger** | `ScrollTrigger` في الـchunks |
| التمرير | **Lenis** | تكامل ScrollTrigger + قواعد reduced-motion |
| 3D | **React Three Fiber + three.js + GLB** | `can1.glb` + تكسترات 6 نكهات + `RoomEnvironment` |
| التنسيق | **Tailwind v4** (CSS-first) | classes مثل `text180`, `paddx`, `bg-foreground` |
| الخطوط | 4 عائلات: عرض ضخم + يدوي (Patrick Hand) + أرقام (Khand) + جسم | `font-patrick-hand`, `font-khand`, `text150/180` |

### 3.2 السمات والتوكنات المستخرجة
- **الألوان:** خلفية كريمية `#f8f8f0` (theme-color) · أمامي بني `#463721` · بيج/ذهبي `#FFE386` · بني فاتح.
- **سلّم الطباعة:** `text150` و`text180` (عناوين ضخمة جداً) · `text36` · `text32` — سلّم واضح من 4 مستويات.
- **الحاوية:** `paddx` (حشوة أفقية موحّدة) · `max-md:` للجوال.
- **الخصائص المتحركة:** `will-change-transform` في كل مكان · `clip-path: inset()` للكشف · `data-speed` و`data-rotate` للبارالاكس · `data-can-spin-runway` للران واي · `data-nav-dark` لثيم التنقل.

### 3.3 تقنيات الحركة المحددة
1. **التثبيت التحويلي (Pin + Scrub):** أقسام بأرفاع `320vh` / `calc(100vh+20vw)` مع `sticky` — البطل يتحول مع التمرير.
2. **الكشف بالقناع:** `clip-path: inset(0 100% 0 0)` → `inset(0)` للعناوين والأزرار.
3. **البارالاكس متعدد الطبقات:** سرعات `-0.05 / -0.07 / 0.06 / -0.1` ودورانات `0 / 30 / 20 / -15`.
4. **شريط التقدم السردي:** عنصر يمتلئ مع التمرير («CANNED 069»).
5. **الران واي/الماركي:** سمة `data-can-spin-runway` لحركة نص مجرى.
6. **الكولاج المائل:** صور بإطارات ودورانات بسيطة.
7. **اللعبة:** canvas تفاعلي بعدّاد نقاط.

## 4) ما الذي ننقله إلى عويق 3.0 (وما الذي لا ننقله)

### ✅ ننقله (منهجية مباشرة)
| المنهجية | التطبيق على عويق |
|---|---|
| **عمود فقري تحويلي واحد** | الزجاجة 3D تتحول عبر الحضارات الأربع (مصر→بابل→اليونان→الصين) — كل حضارة تغيّر مادة/لون/نقش الزجاجة |
| **التثبيت حول البطل** | مشاهد مثبّتة حول الزجاجة والنص يتبدّل حولها |
| **كشف المعلومات مع التحول** | كل حضارة تُكشف مع وصول الزجاجة لمرحلتها |
| **كسر الإيقاع** | «سطر الختم» بشكل ران واي/ماركي بين الحكاية والمجموعة |
| **البارالاكس متعدد الطبقات** | طبقات النقش المسماري بسرعات مختلفة خلف الزجاجة |
| **العناوين بكلمات مفتاحية ملوّنة** | كلمات مفتاحية بالذهبي المسماري على النيلي |
| **بطاقات المنتج بطلها المنتج** | بطاقات المجموعة — الزجاجة/المنتج بطل الخلفية الملوّنة |
| **كولاج مائل** | صور الحضارات بإطارات مائلة |
| **آراء بأسهم واضحة** | كاروسيل آراء بأسهم (لا سحب) |
| **CTA مزدوج** | بطاقة نصية + بطاقة منتج |
| **اللودر بالعدّاد** | لودر بنسبة تحميل + شعار ينبض |

### ⚠ ننقله مع تعديل (فخامة > استعراض)
| عند Palmo | عند عويق |
|---|---|
| جوزة تنفتح بسرعة وحيوية | الزجاجة تتحول **ببطء وسكون** — فخامة لا استعراض |
| لعبة تقطيع فواكه في الفوتر | **تفاعل فاخر هادئ** في الفوتر (انظر المقترح) |
| ألوان مشرقة (أصفر/بني) | **نيلي مهيب + ذهبي مسماري** (المذهب أ المعتمد) |
| نصوص يدوية مرحة | خط عربي فاخر (Lyon Arabic Display) + لاتيني (Ador) |

### ❌ لا ننقله (لا يخدم عويق)
- **لعبة التقطيع الحرفية** — لا تليق بفخامة العطر (لكن نأخذ فكرة «الفوتر تفاعلي»).
- **الخلفيات الكريمية المشرقة** — عويق ليلي/داكن.
- **المنتج الواحد** — عويق أربعة منتجات (الحضارات).

## 5) مقترحات التطبيق التفصيلية (مربوطة بمراحل الخطة)

### مقترح 1 — «العمود الفقري التحويلي» (المرحلة 3: الحكاية)
**الفكرة:** بدلاً من فصول تحريرية ثابتة، الزجاجة 3D هي **البطل المتحرك** عبر الحكاية:
- **المشهد أ (مصر):** الزجاجة بذهب فرعوني + نقش هيروغليفي → تتحول مع التمرير.
- **المشهد ب (بابل):** الزجاجة تُنقش بمسماريات (أصل A2) — لحظة الذروة التحويلية.
- **المشهد ج (اليونان):** الزجاجة رخامية بيضاء/ذهبية.
- **المشهد د (الصين):** الزجاجة خزفية زرقاء/ذهبية.
- **الختام:** الزجاجة تستقر في اليدين (أصل الأيدي) → تنفتح على المجموعة.

**التقنية:** قسم واحد `h-[400vh]` مع `sticky` — الزجاجة في المنتصف، وكل حضارة تُبدّل مادة/لون/نقش الزجاجة عبر GSAP scrub. النصوص تُثبّت حولها وتتبدّل.

**يخدم:** متطلب العميل 1 (الحضارات صريحة) + 3 (الزجاجة بطل) + 4 (سرد سلس).

### مقترح 2 — «الران واي» بين الحكاية والمجموعة (المرحلة 3/4)
**الفكرة:** بدل سطر ختم ثابت، شريط متحرك يجري: **«كل دفعة تحمل رقمها الخاص»** — نص مجرى (marquee) بنقش مسماري خفيف. كسر إيقاع بصري قبل المجموعة.

**التقنية:** عنصر `data-can-spin-runway` — نص متحرك أفقياً بـGSAP، يتوقف عند الوصول للمجموعة.

### مقترح 3 — بطاقات المجموعة بخلفية ملوّنة (المرحلة 4)
**الفكرة:** كل بطاقة منتج بخلفية لون الحضارة (نيلي/ذهبي/أبيض/أزرق) مع الزجاجة/المنتج بطل البطاقة + أشكال مسمارية في الزوايا + اختيار العبوة (Single/Discovery Set) + السعر + زر إضافة.

**التقنية:** `clip-path` للون الخلفية + `canvas` للمنتج + hover يكشف الزخرفة.

### مقترح 4 — الفوتر التفاعلي الفاخر (المرحلة 6)
**الفكرة:** بدل لعبة التقطيع، **«لحظة عطر» هادئة**: الزجاجة 3D صغيرة في الفوتر، وعند مرور المؤشر/اللمس **تتوهج وتطلق رذاذاً ناعماً** (جزيئات) — تفاعل فاخر لا لعبة. أو: عدّاد «رقم الدفعة» الذي يتغير مع التمرير.

**التقنية:** canvas جزيئات خفيف + GSAP. بديل: صورة ثابتة مع توهج CSS.

### مقترح 5 — اللودر بالعدّاد (المرحلة 2 — تحسين)
**الفكرة:** لودر بنسبة تحميل (0→100%) + شعار ينبض + طبقات نقش مسماري تتحرك بسرعات مختلفة (بارالاكس أثناء التحويل).

### مقترح 6 — البارالاكس متعدد الطبقات (كل الأقسام)
**الفكرة:** طبقات النقش المسماري (A1/A4) خلف المحتوى بسرعات سالبة مختلفة — عمق فاخر غير مكلف.
